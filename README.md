
# Adaptive Multimodal RAG

An adaptive multimodal Retrieval-Augmented Generation system
that retrieves and reasons over multiple modalities such as text,
images, tables, and documents.

## Project Status

🚧 Currently under development.

## Objectives

- Multimodal document ingestion
- Text and image processing
- Multimodal embeddings
- Adaptive retrieval
- Reranking
- Multimodal generation
- Evaluation of retrieval and generation quality
